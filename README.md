# 眺望 · EyeRest

一个简洁、离线、低资源占用的 Windows 20-20-20 护眼提醒工具。
[](https://github.com/cimuyang/eyerest/blob/main/Introduction.svg)

## 已实现

- 工作间隔可设置为 1–180 分钟，默认 20 分钟。
- 每次休息 20 秒，显示柔和的全屏倒计时。
- 默认先显示温和提醒，可立即休息、推迟 5 分钟或跳过本次。
- 严格模式会在到时后直接进入休息界面。
- 只累计活跃使用时间：空闲 5 分钟、锁屏及睡眠期间暂停累计。
- 检测到全屏应用时延后弹出提醒。
- 支持暂停 1 小时、立即休息、登录后自动启动。
- 单进程运行；退出后不保留后台服务。
- 配置仅保存在本机 `%LOCALAPPDATA%\EyeRest\settings.ini`。

## 使用方法

打开dist文件夹，启动 `EyeRest.exe` 后，程序仅显示在任务栏通知区域：

- 双击托盘图标打开设置。
- 右键托盘图标可以立即休息、暂停、切换严格模式或退出。
- 休息界面可以按 `Esc` 提前结束，不会锁定电脑。

## 资源占用原则

程序使用原生 Win32 API，没有浏览器内核、运行时框架、网络请求或数据库。后台仅保留隐藏消息窗口和托盘图标，每 5 秒进行一次轻量状态检查，休息界面只在提醒时创建。实际内存和 CPU 占用应以目标电脑上的 Release 版本为准。

## 隐私

程序不联网，不采集窗口标题、键盘内容或浏览历史。它只读取 Windows 提供的“距离上次输入的时间”、会话锁定状态和前台窗口边界，用于判断是否应累计时间或延后提醒。
